## 🤖 CONFIGURACIÓN DE IA

### Opción A: Ollama (Local, 100% Gratis)

1. Descargar e instalar: https://ollama.ai/
2. Abrir PowerShell y ejecutar:
   ```powershell
   ollama pull codellama
   ```
3. **¡Listo!** CubaCodex detectará automáticamente

### Opción B: Google Gemini (Online, Gratis)

1. Ir a: https://aistudio.google.com/app/apikey
2. Crear nueva API Key
3. Configurar en CubaCodex

## 📋 PRIMEROS PASOS

1. **Crear un archivo nuevo**
   - Clic en el botón `+` en el explorador
   - Escribe el nombre (ej: `main.js`)
   - Enter

2. **Escribir código**
   - Escribe en el editor
   - Usa Ctrl+Space para autocompletado

3. **Usar la IA**
   - Abre el panel lateral derecho
   - Escribe: "Crea una función que suma dos números"
   - Clic en "Generar"

4. **Guardar el archivo**
   - Clic en el icono de guardar
   - Elige dónde guardar

## 🚨 PROBLEMAS COMUNES

### "Windows SmartScreen impidió el inicio"

Esto es **NORMAL** para aplicaciones nuevas.

**Solución:**
1. Clic en "Más información"
2. Clic en "Ejecutar de todos modos"

### "No se detecta Ollama"

1. Verifica que Ollama está ejecutándose
2. Abre PowerShell: `ollama list`
3. Verifica que tengas el modelo: `ollama pull codellama`

### "El icono no se muestra"

1. Windows → Configuración → Personalización → Iconos
2. Selecciona "Iconos grandes"
3. Verifica que la caché de iconos esté actualizada
