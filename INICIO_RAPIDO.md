# 🚀 CUBACODEX - DESCARGAR .EXE (GitHub Actions)

## ⚡ MÉTODO MÁS FÁCIL

**¡No necesitas Rust, Node ni compilar nada!**

1. Sube el código a GitHub
2. Espera el build automático (5-10 min)
3. Descarga el .exe desde Actions

---

## 📋 PASOS RÁPIDOS

### PASO 1: Subir a GitHub

Crea un repositorio en: https://github.com/new

Luego, en `C:\Users\Administrator\Documents\cubacodexx`:

```bash
# Clona esto y ajusta TU-USUARIO
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/TU-USUARIO/cubacodex.git
git push -u origin main
```

### PASO 2: Descargar Build

1. Ir a: https://github.com/TU-USUARIO/cubacodex/actions
2. Esperar ✓ verde
3. Bajar a **Artifacts**
4. Descargar: `cubacodex-installer-msi`

### PASO 3: Instalar y Usar

1. Descomprimir
2. Ejecutar: `cubacodex_1.0.0_x64_en-US.msi`
3. ¡Listo!
